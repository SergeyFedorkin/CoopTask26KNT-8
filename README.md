# Бот-дневник для Telegram

Личный дневник студента в одном чате: расписание, домашка с дедлайнами, утренняя сводка и подсчёт оценок.
Написан на Python и aiogram 3.

## Что умеет

**Расписание.** Подключаешь группу один раз (`/group 26КНТ-8`), дальше `/today`, `/tomorrow` и `/week` показывают пары. Расписание берётся из RUZ ВШЭ, а если он недоступен, из Google-таблицы факультета. Свои пары (кружки, консультации, подработка) добавляются через `/addlesson`.

**Домашка и дедлайны.** `/add` записывает задание по шагам или одной строкой: `/add матан; №1.2–1.5; пт 18:00`. Срок можно писать по-человечески: `завтра`, `пт`, `25.10 18:00`, `+3`, `через неделю` или `пара` (к следующей паре по расписанию). `/hw` показывает список: просрочено, горит, на подходе. Задания отмечаются выполненными одной кнопкой.

**Напоминания.** Бот сам пишет перед дедлайном. По умолчанию за сутки и за 3 часа, это меняется командой `/remind 48 24 3`.

**Утренняя сводка.** Каждое утро: пары на сегодня, что надо сдать сегодня и завтра, что просрочено. Время настраивается: `/summary 07:00`, выключить: `/summary off`.

**Оценки и накоп.** Задаёшь формулу предмета (`/formula Матан: КР 0.3, экзамен 0.5, ДЗ 0.2`), вносишь оценки (`/grade матан КР 8`), и `/grades` показывает текущий накоп и сколько нужно получить на оставшихся элементах, чтобы выйти на 4, 6, 8 или 10.

## Запуск

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Поставь зависимости:
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```
3. Скопируй `.env.example` в `.env`, впиши `BOT_TOKEN` и свой Telegram ID в `ALLOWED_USERS` (узнать ID можно у [@userinfobot](https://t.me/userinfobot)).
4. Запусти: `python bot.py`
5. В Telegram открой бота, нажми `/start` и подключи группу.

База данных `diary.db` создаётся автоматически рядом с `bot.py`.

## Все команды

| Команда | Что делает |
|---|---|
| `/group 26КНТ-8` | подключить группу (RUZ, а при недоступности таблица факультета) |
| `/sheet 26КНТ-8` | брать расписание сразу из Google-таблицы |
| `/today` `/tomorrow` `/week` | пары с навигацией по дням |
| `/addlesson` `/lessons` | свои пары, еженедельные или разовые |
| `/add` `/hw` | домашка: добавить, список, отметить |
| `/remind` | за сколько часов напоминать |
| `/summary` | время утренней сводки |
| `/formula` `/grade` `/grades` | формула предмета, оценки, накоп |
| `/delgrade` `/delsubject` | убрать оценку или предмет |
| `/settings` `/help` `/cancel` | настройки, справка, отмена ввода |

## Работа на сервере

Если бота нужно держать запущенным постоянно, смотри [DEPLOY.md](DEPLOY.md): там пошаговая настройка сервера и автодеплой из GitHub. Если Telegram у тебя тормозит, пропиши в `.env` прокси: `TG_PROXY=socks5://...`.

## Из чего состоит

```

ruz.py              клиент RUZ ВШЭ
sheet.py            расписание из Google-таблицы
schedule_data.py    выбор источника расписания + кэш + свои пары
schedule_texts.py   тексты «день» и «неделя»
homework_logic.py   статусы и формат домашки
grades_logic.py     формула оценки и накоп
summary.py          утренняя сводка
scheduler.py        фоновые напоминания и сводка
keyboards.py        кнопки
utils.py            разбор дат и форматирование
handlers/           обработчики команд по темам
tests/              автотесты
deploy/             файлы для сервера
```
